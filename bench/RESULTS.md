## How to read this

- Score range across the set: **50–83** on a 0–100 scale.
- Short answers still scored well: `tx-weak` 53 (16 words), `behavioral-weak` 50 (14 words), `no-answer` 50 (11 words). Length is being rewarded, not correctness.
- Every score came from the **heuristic fallback**; no LLM key was configured, so the rubric evaluator never ran. These numbers prove the pipeline works, not that it grades like a human.
- To benchmark the rubric path: set `LLM_API_KEY` (or `GEMINI_API_KEY`), fill `human_score` in `bench/answers.csv`, then re-run.
- Unlabelled answers are excluded from MAE, ±10 and Spearman, so no agreement number is claimed for them.
